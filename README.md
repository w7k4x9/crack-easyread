# 크랙 크게 읽기

크랙(crack.wrtn.ai) 채팅을 눈 편하게 읽기 위한 Tampermonkey 유저스크립트입니다. 하는 일은 두 가지뿐이에요.

- **글자 크기 키우기**: 채팅 본문 글자 크기와 줄 간격을 조절합니다.
- **대사 강조**: `"..."`, `“...”` 따옴표로 둘러싼 대사에 반투명 강조를 깝니다.

크랙 화면 구조(DOM)나 입력창은 건드리지 않습니다. 글자 크기는 CSS로 바꾸고, 강조는 브라우저의 하이라이트 기능(CSS Custom Highlight API)으로 덧칠만 합니다. 그래서 모델 선택 메뉴가 잘리는 등의 레이아웃 문제가 생기지 않아요.

## 설치

Tampermonkey가 설치된 상태에서 아래 링크를 누르고 **설치**를 누르면 끝입니다. 나중에 고친 버전도 Tampermonkey가 알아서 업데이트해요.

**[▶ 설치하기](https://raw.githubusercontent.com/w7k4x9/crack-easyread/main/crack-easyread.user.js)**

## 사용

크랙 페이지에서 Tampermonkey 아이콘을 누르면 아래 메뉴가 나옵니다.

- **설정 열기**: 오른쪽 위에 설정 창이 뜹니다. 슬라이더로 글자 크기(14–30px), 줄 간격, 대사 강조 켜기/끄기, 강조 진하기를 조절해요. 바꾼 값은 바로 적용되고 저장됩니다. ×나 Esc로 닫아요.
- **글자 크게 (+1)** / **글자 작게 (−1)**
- **대사 강조 켜기/끄기**

기본값은 글자 19px, 줄 간격 1.75, 강조 진하기 14%입니다.
