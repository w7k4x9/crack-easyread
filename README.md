# 크랙 크게 읽기

크랙(crack.wrtn.ai) 채팅을 눈 편하게 읽기 위한 아주 작은 Chrome 확장입니다. 하는 일은 두 가지뿐이에요.

- **글자 크기 키우기**: 채팅 본문 글자 크기와 줄 간격을 조절합니다.
- **대사 강조**: `"..."`, `“...”` 따옴표로 둘러싼 대사에 반투명 강조를 깝니다.

크랙 화면 구조(DOM)나 입력창은 건드리지 않습니다. 글자 크기는 CSS로 바꾸고, 강조는 브라우저의 하이라이트 기능(CSS Custom Highlight API)으로 덧칠만 합니다. 그래서 모델 선택 메뉴가 잘리는 등의 레이아웃 문제가 생기지 않아요.

## 설치

1. 이 저장소를 내려받아 압축을 풉니다. 초록색 **Code** 버튼에서 **Download ZIP**을 누르면 돼요.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 크랙 탭을 새로고침합니다.

## 설정

툴바의 확장 아이콘을 누르면 아래 항목을 조절할 수 있습니다. 바꾼 값은 바로 적용되고 저장돼요.

- 글자 크기: 14–30px, 기본 19px
- 줄 간격
- 대사 강조 켜기/끄기
- 강조 진하기

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 정의. crack.wrtn.ai에서만 동작하며 권한은 설정 저장용 `storage` 하나입니다. |
| `content.js` | 글자 크기 CSS 적용과 대사 강조 |
| `popup.html`, `popup.js` | 설정 창 |
